# Retail Lakehouse Architecture using Databricks & Delta Lake

## Overview
Built an end-to-end Retail Lakehouse pipeline using Databricks, Delta Lake, PySpark, Structured Streaming, Auto Loader, and SQL Analytics.

## Architecture
Bronze → Silver → Gold Architecture

## Features
- Bronze ingestion layer
- Silver data cleaning transformations
- Gold business aggregations
- Delta Lake optimizations
- Structured Streaming
- Auto Loader pipeline
- SQL analytics
- Interactive dashboard

## Technologies Used
- Databricks
- PySpark
- Delta Lake
- Structured Streaming
- Auto Loader
- SQL
- Databricks SQL Dashboard

## Dashboard
Includes:
- Daily sales trend
- Top customers revenue
- Category sales distribution
- Total sales KPI

## Project Outcome
Created a scalable modern data engineering pipeline supporting batch + streaming analytics for retail business reporting.
